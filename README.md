# NOC Tools

> **Uma ferramenta para quem procura soluções e conhecimento.**

Plataforma Open Source para diagnóstico de redes, desenvolvida para centralizar testes, facilitar validações técnicas e incentivar a autonomia de profissionais de TI.

---

# 📖 Sobre o Projeto

O NOC Tools nasceu a partir de uma necessidade real vivida durante uma mudança na infraestrutura de DNS de um provedor de internet.

Na ocasião, diversos testes utilizando ferramentas como `dig` e `curl` precisavam ser executados repetidamente para validar o ambiente.

Mesmo sem uma solicitação formal, esses testes foram realizados por iniciativa própria e compartilhados com a equipe para auxiliar na tomada de decisões.

Dessa experiência surgiram os dois primeiros scripts do projeto:

- dns_cluster_check.sh
- dns_edge_check.sh

O que inicialmente era apenas uma automação passou a evoluir para algo muito maior.

Hoje o objetivo é construir uma plataforma Open Source para diagnóstico de redes que possa ajudar profissionais em qualquer lugar.

---

# 🎯 Nossa Missão

Fornecer ferramentas simples, acessíveis e confiáveis para que qualquer pessoa possa realizar diagnósticos de rede com autonomia.

Mais do que executar testes, queremos incentivar o aprendizado, compartilhar conhecimento e reduzir a dependência de consultas constantes a terceiros.

Se uma única pessoa conseguir resolver um problema mais rapidamente graças ao NOC Tools, o projeto já terá cumprido parte da sua missão.

---

# 💙 Nossa Filosofia

O NOC Tools é guiado por alguns princípios simples:

- Simplicidade acima da complexidade.
- Ensinar enquanto ajuda.
- Promover autonomia técnica.
- Compartilhar conhecimento.
- Gerar evidências organizadas.
- Ser útil para qualquer profissional de redes.
- Evoluir continuamente através da comunidade.

---

# 👥 Para quem é o projeto?

O NOC Tools foi criado para qualquer pessoa que trabalhe ou estude redes.

Entre eles:

- Analistas de NOC
- Técnicos de suporte
- Provedores de Internet (ISPs)
- Administradores de Sistemas
- Engenheiros de Redes
- Estudantes
- Entusiastas de infraestrutura

O projeto não foi criado para um cargo específico.

Ele foi criado para quem procura soluções e conhecimento.

# 🚧 Status do Projeto
